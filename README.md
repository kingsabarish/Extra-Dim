# Brightness Reducer

A simple Android app that reduces screen brightness below the system's default minimum limit.

## Problem

Android only lets users dim the screen down to a fixed system minimum brightness. For reading in a dark room, or to reduce eye strain at night, that minimum can still be too bright. This app applies a software-based overlay dimming layer on top of the screen to go beyond that default limit.

## Features

- Dim the screen below the system's minimum brightness limit
- Simple, single-purpose UI (no bloat)
